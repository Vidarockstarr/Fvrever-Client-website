## 📖 Acerca del proyecto

**FVREVER Client** es un proyecto enfocado en ofrecer una experiencia de Minecraft personalizada mediante un launcher propio y una plataforma web moderna.

El proyecto cuenta con un sitio oficial y un sistema de administración desde el que se pueden gestionar diferentes aspectos de la plataforma.

## ✨ Características

- 🎮 **Launcher propio:** acceso a la experiencia de FVREVER Client.
- 🌐 **Sitio web oficial:** interfaz moderna con diseño adaptable.
- 🖼️ **Galería personalizable:** espacios para mostrar imágenes del proyecto.
- 🛠️ **Panel de administración:** gestión del contenido y las secciones del sitio.
- 📦 **Gestión de versiones:** administración de archivos y lanzamientos del launcher.
- 🔑 **Gift Keys:** sistema de generación y administración de códigos.
- 📱 **Diseño responsive:** compatible con dispositivos móviles y escritorio.

## 🖥️ Tecnologías utilizadas

## 🔐 Administración

El proyecto incluye un panel administrativo para gestionar el contenido del sitio, las imágenes de la galería, las versiones del launcher y los Gift Keys.

El acceso está protegido mediante autenticación. Las credenciales y los tokens se gestionan mediante variables de entorno del servidor.
