## 🌷 Sobre FVREVER

**FVREVER** es un proyecto que combina un launcher personalizado de Minecraft con una plataforma web y un sistema privado de estadísticas.

El objetivo es construir un ecosistema completo que permita ofrecer una experiencia cómoda a los usuarios, administrar el contenido del proyecto y conocer su crecimiento mediante herramientas de análisis.

El proyecto está dividido en diferentes componentes que trabajan en conjunto.

## 🎮 FVREVER Client

El launcher es el componente principal del proyecto. Está pensado para facilitar el acceso a Minecraft mediante una experiencia personalizada.

### Características

- 🚀 Inicio rápido y experiencia optimizada.
- 🎨 Interfaz personalizada.
- ⚙️ Configuración y personalización.
- 📦 Gestión de instalaciones y versiones.
- 🌱 Mejoras y optimizaciones constantes.

## 🌐 Sitio web oficial

El sitio web funciona como punto central de acceso a FVREVER.

### Características

- 🖥️ Diseño moderno y adaptable.
- 🖼️ Galería visual personalizable.
- 📥 Sección de descargas del launcher.
- 📋 Información y novedades del proyecto.
- 🛠️ Integración con el sistema administrativo.

**Sitio oficial:** https://fvreverclient.vercel.app/

## 🛠️ Panel de administración

FVREVER cuenta con un panel administrativo para gestionar diferentes aspectos de la plataforma sin tener que modificar manualmente cada sección del sitio.

### Funciones

- 📊 Resumen general.
- 📝 Edición del contenido de la página.
- 🖼️ Administración de imágenes de la galería.
- 📦 Subida y gestión de versiones del launcher.
- 📥 Administración de archivos descargables.
- 🔑 Generación y gestión de Gift Keys.
- ⚙️ Configuración del contenido del proyecto.

El acceso administrativo está protegido mediante autenticación.

## 📊 FVREVER Analytics

**FVREVER Analytics** es el sistema complementario encargado de recopilar y visualizar estadísticas relacionadas con el crecimiento y la actividad del launcher.

Es un proyecto independiente que complementa a FVREVER Client.

### Estadísticas disponibles

- 📥 Total de instalaciones.
- 👥 Instalaciones activas durante el día.
- 🚀 Inicios del launcher.
- 🌍 Distribución aproximada por países.
- 🏷️ Distribución de versiones.
- 📈 Eventos y estadísticas de actividad.

### 🔒 Privacidad y seguridad

La privacidad es una parte importante de FVREVER Analytics.

- Identificadores aleatorios de instalación.
- No se requiere una cuenta personal para registrar estadísticas de instalación.
- Los datos opcionales de uso se gestionan por separado.
- La información geográfica es aproximada.
- La IP no se incluye en el JSON de telemetría enviado por el cliente.
- El dashboard tiene acceso restringido.

**Repositorio de Analytics:**  
https://github.com/Vidarockstarr/fvrever-client-analytics

**Dashboard:**  
https://fvrever-client-analytics.vercel.app/

## 🔐 Seguridad

FVREVER utiliza mecanismos de protección para sus herramientas administrativas y servicios internos.

- Autenticación para los paneles privados.
- Variables de entorno para credenciales y tokens.
- Protección de endpoints administrativos.
- Separación entre servicios públicos y privados.

**Importante:** las credenciales, tokens y claves privadas no deben publicarse en los repositorios.
